## 🛠️ Technology Stack
*   **Frontend**: Static HTML5, Vanilla CSS3 (Glassmorphism & Custom Properties), performant ES6+ JavaScript.
*   **Graphics**: HTML5 Canvas 2D running a custom numerical-gradient field solver.
*   **Audio**: Web Audio API (`AudioContext`, `AnalyserNode`, `OscillatorNode`, and `MediaStreamAudioSourceNode`).
*   **Web3**: Ethers.js (v6) for wallet connection and dynamic ENS name resolution.
*   **Smart Contract**: Solidity (`ERC721URIStorage`, `Ownable`, `ReentrancyGuard`).
*   **Hosting**: Fully decentralized hosting on **IPFS** via **4EVERLAND**.
